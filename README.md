# Silent Look — CTF Writeup

> A short reconnaissance challenge about collecting information on a target without directly interacting with it.

| Challenge | Topic | Focus |
| :--- | :--- | :--- |
| **Silent Look** | Reconnaissance | Passive information gathering |

## Challenge Description

> Gathering as much information as possible without establishing contact between the pen tester and the target which you are collecting information.

The objective is to identify the information-gathering technique described by the question.

---

## Analysis

The important phrase is **"without establishing contact"** with the target.

- The goal is to **collect information** about a target.
- The process avoids **direct contact or interaction** with that target.

This is the defining idea behind **passive information gathering**, a reconnaissance approach based on information obtainable without directly engaging the target.

## Answer

```text
passive information gathering
```

---

## Key Takeaway

**Passive information gathering** collects information without directly contacting the target, unlike active reconnaissance, which involves direct interaction.
